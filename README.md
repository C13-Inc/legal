# C13 Inc — Legal Pages

Public-facing legal documents for C13 Inc, published via GitHub Pages.

- [Privacy Policy](https://chrisbarone-c13.github.io/legal/privacy.html)
- [Terms of Service](https://chrisbarone-c13.github.io/legal/terms.html)

These are hosted here as an interim measure so they have stable public URLs.
They are intended to move to `c13inc.com` once that site is live; the working
copies are maintained alongside the website source.

Static HTML only — no build step, no dependencies. Edits to the files in this
repository publish automatically.
